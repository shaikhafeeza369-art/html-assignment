Technical Terms

Temporary memory used by the laptop.
SSD
Fast storage for files and applications.
CPU
Main processor of the computer.
GPU
Handles graphics and visual processing.
Refresh Rate
Number of screen updates per second.
Battery Capacity
Amount of energy stored in the battery.
